THE MEMORY LINE

Learn → Build → Send → Trigger → Stay → Control → Achieve. The verbs tell the story even when the technical details change.

ATTACKER VIEW

A chain of dependencies

Later actions usually depend on earlier success. No delivery means nothing arrives; no execution means the payload cannot run.

DEFENDER VIEW

Seven chances to intervene

Reduce exposed information, filter delivery, patch software, limit execution, detect persistence, block control traffic, and protect critical data.

ANALYST VIEW

Evidence, not guesswork

A phase describes the attacker’s purpose. Classify an event by what it accomplishes, not merely by the tool or file involved.
